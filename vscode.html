💻 VS Code – Tối Ưu Năng Suất Lập Trình

Phím tắt, tiện ích mở rộng và kỹ thuật debug chuyên nghiệp.

1 Tổng Quan Giao Diện & Thiết Lập Python

Cơ bản

Visual Studio Code (VS Code) là trình soạn thảo mã nguồn miễn phí, nhẹ nhưng cực kỳ mạnh mẽ của Microsoft. Khi mở VS Code lên, bạn sẽ thấy giao diện được chia thành 5 vùng chính — hiểu rõ chúng sẽ giúp bạn thao tác nhanh hơn rất nhiều.

5 Vùng Giao Diện Chính

Vùng Vị trí Chức năng
Activity Bar Thanh dọc ngoài cùng bên trái Chứa các biểu tượng để chuyển đổi giữa các chế độ xem: Explorer, Search, Source Control, Run & Debug, Extensions. Bạn có thể kéo thả để sắp xếp lại hoặc ẩn bớt icon không dùng.
Side Bar Bên trái, cạnh Activity Bar Hiển thị nội dung tương ứng với biểu tượng đang chọn trên Activity Bar. Ví dụ: cây thư mục dự án (Explorer), kết quả tìm kiếm (Search), danh sách thay đổi Git (Source Control).
Editor Vùng trung tâm, chiếm phần lớn màn hình Nơi bạn viết và chỉnh sửa code. Hỗ trợ mở nhiều tab cùng lúc, chia màn hình (split editor) bằng Ctrl+\, và xem song song nhiều file.
Panel Phía dưới Editor Chứa Terminal tích hợp, Output, Problems (lỗi/cảnh báo), và Debug Console. Mở/đóng bằng Ctrl+`. Đây là nơi bạn chạy lệnh mà không cần rời VS Code.
Status Bar Thanh ngang ở dưới cùng Hiển thị thông tin nhanh: nhánh Git hiện tại, ngôn ngữ file, encoding (UTF-8), dòng/cột con trỏ, Python interpreter đang dùng, và các thông báo từ extension.

Thiết Lập Python Interpreter

Khi làm việc với Python trong VS Code, bước đầu tiên là chọn đúng Python interpreter (trình thông dịch). Điều này quyết định phiên bản Python và môi trường ảo nào được dùng khi chạy code.

Cách thực hiện:

  1. Nhấn Ctrl+Shift+P để mở Command Palette — đây là "bộ não" của VS Code, cho phép bạn truy cập mọi lệnh.
  2. Gõ Python: Select Interpreter rồi nhấn Enter.
  3. Chọn phiên bản Python phù hợp từ danh sách. Nếu bạn đang dùng môi trường ảo, hãy chọn interpreter nằm trong thư mục .venv.
Giao diện Command Palette 
# Bước 1: Mở Command Palette
Ctrl+Shift+P

# Bước 2: Gõ lệnh
Python: Select Interpreter

# Bước 3: Chọn interpreter, ví dụ:
Python 3.12.0 (.venv)  ← Ưu tiên chọn cái này
Python 3.12.0 (/usr/bin/python3)
Python 3.11.5 (base: conda)
💡
Mẹo chọn môi trường ảo: Nếu dự án của bạn có thư mục .venv (tạo bằng python -m venv .venv), hãy luôn chọn interpreter bên trong .venv. Điều này đảm bảo các thư viện được cài đặt riêng cho dự án, không ảnh hưởng đến hệ thống. VS Code thường tự phát hiện và gợi ý .venv — bạn chỉ cần xác nhận. Nếu không thấy, hãy nhấn "Enter interpreter path…" rồi trỏ đến .venv/Scripts/python.exe (Windows) hoặc .venv/bin/python (macOS/Linux).

2 Bảng Tra Cứu Phím Tắt Tương Tác

Năng suất

Phím tắt là siêu năng lực của lập trình viên. Thay vì dùng chuột tìm kiếm trong menu, bạn chỉ cần nhấn tổ hợp phím để thực hiện ngay hành động mong muốn. Bảng bên dưới tổng hợp các phím tắt quan trọng nhất — bạn có thể tìm kiếm theo tên hoặc lọc theo danh mục để nhanh chóng tra cứu.

🚀
Bí quyết ghi nhớ: Đừng cố học hết tất cả phím tắt cùng lúc! Mỗi ngày hãy chọn 2–3 phím tắt và ép bản thân dùng chúng thay vì chuột. Sau 1–2 tuần, chúng sẽ trở thành phản xạ tự nhiên. Bạn cũng có thể nhấn Ctrl+K Ctrl+S để mở bảng phím tắt đầy đủ của VS Code và tùy chỉnh theo ý muốn.

3 Top Tiện Ích Mở Rộng (Extensions)

Công cụ

Extensions (tiện ích mở rộng) biến VS Code từ một trình soạn thảo đơn giản thành một IDE toàn diện. Dưới đây là những extension thiết yếu mà mọi lập trình viên Python nên cài đặt ngay.

Cách cài đặt: Nhấn Ctrl+Shift+X để mở bảng Extensions, gõ tên extension, rồi nhấn Install.

Tên Extension Tác giả Công dụng
Python & Pylance Microsoft Hỗ trợ toàn diện cho Python: chạy code, debug, IntelliSense thông minh, auto-import, type checking, và gợi ý code theo ngữ cảnh. Pylance cung cấp phân tích code nhanh chóng và chính xác hơn nhờ engine riêng.
GitLens GitKraken Hiển thị ai đã sửa dòng code nào (git blame), lịch sử commit trực quan, so sánh nhánh, và dòng thời gian thay đổi của file. Không thể thiếu khi làm việc nhóm.
Black Formatter Microsoft Tự động format code Python theo chuẩn Black — "The uncompromising formatter". Giúp code luôn nhất quán, đẹp mắt, không cần tranh luận về style. Kết hợp với "editor.formatOnSave": true để tự format khi lưu file.
Error Lens Alexander Hiển thị lỗi và cảnh báo ngay trên dòng code thay vì chỉ ở tab Problems. Giúp bạn phát hiện và sửa lỗi nhanh hơn nhiều vì không cần di chuyển mắt khỏi code.
Material Icon Theme Philipp Kief Thay thế icon mặc định bằng bộ icon Material Design đẹp mắt, dễ phân biệt. Mỗi loại file (.py, .js, .html…) có icon riêng, giúp nhận diện file nhanh hơn trong Explorer.
Prettier Prettier team Auto-format cho HTML, CSS, JavaScript, JSON, Markdown và nhiều ngôn ngữ khác. Giống như Black nhưng dành cho web development. Đảm bảo code frontend luôn sạch sẽ và thống nhất.
💡
Lưu ý: Đừng cài quá nhiều extension cùng lúc — mỗi extension đều tiêu tốn tài nguyên. Hãy bắt đầu với Python + Pylance và Black Formatter, sau đó bổ sung dần khi thực sự cần thiết. Bạn có thể tắt (Disable) extension cho từng workspace riêng nếu chỉ cần chúng ở một số dự án.

4 Kỹ Thuật Debug Thay Vì print()

Nâng cao

Hầu hết người mới học lập trình đều dùng print() để kiểm tra giá trị biến khi code chạy sai. Cách này đơn giản nhưng cực kỳ kém hiệu quả: bạn phải thêm/xóa hàng loạt print(), chạy lại code nhiều lần, và khó theo dõi luồng thực thi.

VS Code Debugger là giải pháp chuyên nghiệp — cho phép bạn dừng chương trình tại bất kỳ dòng nào, quan sát giá trị tất cả biến, và bước qua từng dòng code một cách có kiểm soát.

Breakpoint — Điểm Dừng

Breakpoint là vị trí bạn muốn chương trình tạm dừng để kiểm tra trạng thái. Cách đặt:

  1. Click vào vùng trống bên trái số dòng (gutter) — một chấm đỏ 🔴 sẽ xuất hiện.
  2. Click lần nữa để xóa breakpoint.
  3. Bạn có thể đặt nhiều breakpoint ở nhiều dòng khác nhau.

Bắt Đầu Debug

Nhấn F5 để bắt đầu debug. Nếu là lần đầu, VS Code sẽ hỏi bạn chọn debug configuration — chọn Python Debugger: Python File để debug file hiện tại.

Python 
# Ví dụ: debug chương trình tính tổng
def tinh_tong(danh_sach):
    tong = 0
    for so in danh_sach:     # ← Đặt breakpoint ở đây
        tong += so              # Quan sát 'tong' thay đổi mỗi vòng lặp
    return tong

diem = [8, 6.5, 9, 7, 10]
ket_qua = tinh_tong(diem)
print(f"Tổng điểm: {ket_qua}")

Các Phím Điều Khiển Debug

Khi chương trình dừng tại breakpoint, thanh công cụ debug xuất hiện ở trên cùng. Bạn dùng các phím sau để điều khiển:

Phím tắt Tên lệnh Chức năng
F10 Step Over Chạy dòng hiện tại và nhảy sang dòng kế tiếp. Nếu dòng đó gọi hàm, hàm được chạy hoàn chỉnh mà không đi vào bên trong.
F11 Step Into Đi vào bên trong hàm đang được gọi ở dòng hiện tại. Dùng khi bạn muốn kiểm tra chi tiết logic bên trong hàm.
Shift+F11 Step Out Chạy hết phần còn lại của hàm hiện tại và quay về dòng gọi hàm. Dùng khi bạn đã kiểm tra xong bên trong hàm và muốn thoát ra.
F5 Continue Tiếp tục chạy chương trình cho đến breakpoint tiếp theo (hoặc kết thúc nếu không còn breakpoint nào).
Shift+F5 Stop Dừng hoàn toàn phiên debug, kết thúc chương trình ngay lập tức.
🚀
Dùng Watch & Variables panel để theo dõi biến: Khi debug, hãy mở Side Bar → Run & Debug (hoặc Ctrl+Shift+D). Bạn sẽ thấy hai panel cực kỳ hữu ích:
• Variables — tự động hiển thị tất cả biến hiện tại và giá trị của chúng (local, global, class attributes).
• Watch — cho phép bạn thêm biểu thức tùy ý để theo dõi. Ví dụ: gõ len(danh_sach) hoặc tong / len(danh_sach) để xem giá trị cập nhật sau mỗi bước debug.
Kết hợp cả hai, bạn có thể hiểu rõ trạng thái chương trình tại mọi thời điểm — hiệu quả gấp nhiều lần so với print()!
⚠️
Lưu ý quan trọng: Để debug Python hoạt động, bạn cần đã cài extension Python Debugger (thường được cài tự động cùng extension Python). Nếu nhấn F5 mà không thấy tùy chọn debug Python, hãy kiểm tra lại extension và đảm bảo đã chọn đúng Python interpreter (Ctrl+Shift+P → Python: Select Interpreter).
