Từ biến, kiểu dữ liệu đến hàm và xử lý lỗi – kèm sandbox chạy mã trực tiếp.

1 Biến, Kiểu Dữ Liệu & F-String

Nền tảng

Python là ngôn ngữ kiểu động (dynamically typed) — bạn không cần khai báo kiểu dữ liệu trước khi gán giá trị. Trình thông dịch sẽ tự suy luận kiểu dựa trên giá trị được gán.

Một quy tắc bắt buộc trong Python là thụt lề (indentation): luôn dùng 4 dấu cách cho mỗi cấp. Python dùng thụt lề để xác định khối lệnh, thay vì dấu ngoặc nhọn {} như các ngôn ngữ khác. Nếu thụt lề sai, chương trình sẽ báo lỗi IndentationError.

Khai báo biến với các kiểu cơ bản

Python có bốn kiểu dữ liệu cơ bản thường gặp nhất: str (chuỗi), int (số nguyên), float (số thực), và bool (luận lý).

Python 
# Chuỗi (str)
ten = "Minh Anh"

# Số nguyên (int)
tuoi = 21

# Số thực (float)
diem_tb = 8.75

# Luận lý (bool)
da_tot_nghiep = False

# Kiểm tra kiểu dữ liệu
print(type(ten))        # <class 'str'>
print(type(tuoi))       # <class 'int'>
print(type(diem_tb))    # <class 'float'>
print(type(da_tot_nghiep)) # <class 'bool'>

F-String – Nội suy chuỗi hiện đại

F-string cho phép chèn giá trị biến hoặc biểu thức trực tiếp vào chuỗi bằng cách đặt tiền tố f trước dấu ngoặc kép và bọc biến trong {}.

Python 
ten = "Minh Anh"
tuoi = 21

# F-string cơ bản
loi_chao = f"Xin chào {ten}, {tuoi} tuổi!"
print(loi_chao)
# → Xin chào Minh Anh, 21 tuổi!

# F-string với biểu thức tính toán
print(f"Năm sinh: {2026 - tuoi}")
# → Năm sinh: 2005

# F-string định dạng số thực (2 chữ số thập phân)
pi = 3.14159265
print(f"Pi ≈ {pi:.2f}")
# → Pi ≈ 3.14
💡
F-string từ Python 3.6+: F-string được giới thiệu trong Python 3.6 và là cách nội suy chuỗi được khuyên dùng nhất hiện nay. Trước đó, lập trình viên thường dùng .format() hoặc toán tử %, nhưng f-string ngắn gọn và dễ đọc hơn nhiều.

2 Cấu Trúc Điều Kiện If – Elif – Else

Luồng điều khiển

Câu lệnh điều kiện cho phép chương trình đưa ra quyết định: thực thi khối lệnh này nếu điều kiện đúng, ngược lại chạy khối khác. Python dùng if, elif (viết tắt của else if) và else.

Ví dụ: Phân loại điểm học sinh

Python 
diem = 7.5

if diem >= 9.0:
    xep_loai = "Xuất sắc"
elif diem >= 8.0:
    xep_loai = "Giỏi"
elif diem >= 6.5:
    xep_loai = "Khá"
elif diem >= 5.0:
    xep_loai = "Trung bình"
else:
    xep_loai = "Yếu"

print(f"Điểm {diem} → Xếp loại: {xep_loai}")
# → Điểm 7.5 → Xếp loại: Khá

Toán tử logic: and, or, not

Python sử dụng từ khóa tiếng Anh thay vì ký hiệu để biểu diễn toán tử logic, giúp mã nguồn đọc tự nhiên như câu văn:

  • and – đúng khi cả hai điều kiện đều đúng
  • or – đúng khi ít nhất một điều kiện đúng
  • not – đảo ngược giá trị logic
Python 
tuoi = 20
co_cccd = True

# Kết hợp nhiều điều kiện
if tuoi >= 18 and co_cccd:
    print("Đủ điều kiện đăng ký")

# Toán tử not
if not da_tot_nghiep:
    print("Vẫn đang học")

Biểu thức điều kiện (Ternary)

Python cho phép viết câu điều kiện trên một dòng duy nhất, rất hữu ích cho các phép gán đơn giản:

Python 
diem = 6.0

# Cú pháp: giá_trị_đúng if điều_kiện else giá_trị_sai
ket_qua = "Đậu" if diem >= 5 else "Rớt"

print(f"Kết quả: {ket_qua}")
# → Kết quả: Đậu

3 Vòng Lặp For & While

Vòng lặp

Vòng lặp cho phép thực thi một khối lệnh nhiều lần. Python cung cấp hai loại vòng lặp chính: for (lặp qua tập hợp) và while (lặp khi điều kiện còn đúng).

Vòng lặp for với range() và enumerate()

Python 
# range(start, stop, step) — stop không bao gồm
for i in range(1, 6):
    print(f"Lần lặp thứ {i}")
# → Lần lặp thứ 1, 2, 3, 4, 5

# Lặp qua danh sách
mon_hoc = ["Toán", "Lý", "Hóa", "Anh"]

for mon in mon_hoc:
    print(f"Môn: {mon}")

# enumerate() — lấy cả chỉ số lẫn giá trị
for idx, mon in enumerate(mon_hoc, start=1):
    print(f"{idx}. {mon}")
# → 1. Toán  2. Lý  3. Hóa  4. Anh

Vòng lặp while

Python 
# While — lặp khi điều kiện còn True
dem = 5

while dem > 0:
    print(f"Đếm ngược: {dem}")
    dem -= 1

print("🚀 Phóng!")

break và continue

Hai từ khóa đặc biệt giúp kiểm soát luồng vòng lặp:

  • break – thoát ngay khỏi vòng lặp, bỏ qua tất cả các lần lặp còn lại.
  • continue – bỏ qua phần còn lại của lần lặp hiện tại, nhảy đến lần lặp tiếp theo.
Python 
# break — dừng khi gặp số chia hết cho 7
for n in range(1, 100):
    if n % 7 == 0:
        print(f"Số chia hết cho 7 đầu tiên: {n}")
        break

# continue — bỏ qua số chẵn, chỉ in số lẻ
for n in range(1, 11):
    if n % 2 == 0:
        continue
    print(n, end=" ")
# → 1 3 5 7 9
💡
Mẹo – Dùng enumerate() thay chỉ số thủ công: Thay vì tạo biến đếm riêng rồi tăng dần (i = 0; i += 1), hãy dùng enumerate(). Cách này ngắn gọn hơn, ít lỗi hơn, và là phong cách Pythonic được cộng đồng khuyên dùng.

4 Cấu Trúc Dữ Liệu: List, Tuple, Dict, Set

Dữ liệu

Python cung cấp bốn cấu trúc dữ liệu tích hợp sẵn. Mỗi loại có đặc tính riêng phù hợp cho các trường hợp sử dụng khác nhau.

Bảng so sánh

Cấu trúc Cú pháp Có thứ tự Sửa đổi được Cho trùng
List [1, 2, 3] ✅ Có ✅ Có ✅ Có
Tuple (1, 2, 3) ✅ Có ❌ Không ✅ Có
Dict {"a": 1} ✅ Có (3.7+) ✅ Có ❌ Key duy nhất
Set {1, 2, 3} ❌ Không ✅ Có ❌ Không

List Comprehension – Tạo list một dòng

List comprehension là cách viết gọn để tạo list mới từ iterable, kết hợp vòng lặp và điều kiện lọc trong một biểu thức:

Python 
# Tạo list bình phương các số chẵn từ 1 đến 10
binh_phuong_chan = [x**2 for x in range(1, 11) if x % 2 == 0]
print(binh_phuong_chan)
# → [4, 16, 36, 64, 100]

# Chuyển danh sách tên thành chữ hoa
ten_list = ["an", "bình", "châu"]
ten_hoa = [t.upper() for t in ten_list]
print(ten_hoa)
# → ['AN', 'BÌNH', 'CHÂU']

Dictionary – Duyệt với .items()

Dictionary lưu dữ liệu theo cặp key: value. Dùng .items() để lấy cả key lẫn value trong vòng lặp:

Python 
sinh_vien = {
    "ten":   "Minh Anh",
    "tuoi":  21,
    "nganh": "Khoa học Máy tính",
    "gpa":   3.65,
}

# Duyệt qua tất cả các cặp key-value
for key, value in sinh_vien.items():
    print(f"{key:8} → {value}")

# → ten      → Minh Anh
# → tuoi     → 21
# → nganh    → Khoa học Máy tính
# → gpa      → 3.65

# Truy cập an toàn với .get()
email = sinh_vien.get("email", "Chưa có")
print(f"Email: {email}")
# → Email: Chưa có

5 Khai Báo Hàm & Xử Lý Ngoại Lệ

Hàm & lỗi

Hàm (def) giúp tái sử dụng mã nguồn, còn try/except giúp chương trình xử lý lỗi mượt mà mà không bị crash.

Khai báo hàm với type hints và tham số mặc định

Python hỗ trợ type hints (gợi ý kiểu) từ phiên bản 3.5+. Chúng không ép kiểu tại runtime nhưng giúp IDE, linter và đồng nghiệp hiểu rõ ý định của bạn.

Python 
def tinh_hoc_phi(
    so_tin: int,
    gia_tin: float = 550_000,
    giam_gia: float = 0.0
) -> float:
    """Tính học phí dựa trên số tín chỉ.

    Args:
        so_tin:   Số tín chỉ đăng ký.
        gia_tin:  Giá mỗi tín chỉ (mặc định 550.000đ).
        giam_gia: Phần trăm giảm giá (0.0 – 1.0).

    Returns:
        Tổng học phí sau giảm giá.
    """
    tong = so_tin * gia_tin
    return tong * (1 - giam_gia)

# Gọi hàm với tham số mặc định
print(tinh_hoc_phi(18))
# → 9900000.0

# Gọi hàm với tham số keyword
print(tinh_hoc_phi(18, giam_gia=0.1))
# → 8910000.0  (giảm 10%)

Xử lý ngoại lệ: try / except / finally

Khi chương trình gặp lỗi (ví dụ chia cho 0, truy cập file không tồn tại), Python sẽ ném ra một ngoại lệ (exception). Dùng try/except để bắt và xử lý lỗi thay vì để chương trình crash.

Python 
def chia_so(a: float, b: float) -> float | None:
    """Chia a cho b với xử lý lỗi."""
    try:
        ket_qua = a / b
    except ZeroDivisionError:
        print("❌ Lỗi: Không thể chia cho 0!")
        return None
    except TypeError as e:
        print(f"❌ Lỗi kiểu dữ liệu: {e}")
        return None
    else:
        # Chạy khi KHÔNG có lỗi
        print(f"✅ Kết quả: {ket_qua:.2f}")
        return ket_qua
    finally:
        # LUÔN chạy dù có lỗi hay không
        print("📋 Phép tính đã hoàn tất.")

chia_so(10, 3)   # ✅ Kết quả: 3.33
chia_so(10, 0)   # ❌ Lỗi: Không thể chia cho 0!
⚠️
Tránh dùng bare except: Đừng viết except: trống (không chỉ rõ loại lỗi). Cách này sẽ bắt tất cả ngoại lệ, kể cả KeyboardInterrupt và SystemExit, khiến bạn rất khó debug. Luôn chỉ định loại ngoại lệ cụ thể như except ValueError hoặc ít nhất dùng except Exception.
